# pact-lsp

Language support for [Pact](https://github.com/arj4web/Pact), the session-typed extension of AnvilHDL: diagnostics, navigation, completion, syntax highlighting and session-state hints.

Requires a Pact compiler with AST output (`-ast`); set its path in `pact.executablePath`. See the [repository README](https://github.com/AnvilHDL/anvil-lsp) for details.
